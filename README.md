# NICTA PNG Cyber Security 2026  
## About the Project  

This API showcases best practise in implementing Multi-Factor and password strength check to make sure your password is strong and unhackable.  

## What we expect you to have  
- Nodejs installed (v22 or latest)  
- PostgreSQL Database (Or any Database of your choice)  
- Code Editor (VS Code)  
- Git

## Core Technologies
**FRONTEND**  
- React.js
- Tailwind CSS  

**BACKEND**  
- Express.js  
- PostgreSQL + Prisma ORM   

This project uses `Typescript` in both the frontend and backend. 

## Get Started.  
To get started with this project, you can `clone` or `fork` the repository and make it yours forever.  

1. Clone the repo  

```bash
git clone 
```  
2. Install Dependencies  

```bash
npm install
```  

## Run the App  
After the installation has completed, run the app in your local machine.  

```bash
npm run dev
```
